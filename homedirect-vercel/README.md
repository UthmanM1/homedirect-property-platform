# HomeDirect Property Selling Platform MVP

Original portfolio concept created to demonstrate UX/UI and product thinking for a property-selling platform MVP.

## Deploy to Vercel
This is a static HTML/CSS prototype. No build command is required.

1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Import the repository into Vercel.
4. Framework Preset: Other.
5. Build Command: leave empty.
6. Output Directory: `.`

## Main screens
- `index.html` Home
- `onboarding.html` Seller onboarding
- `services.html` Optional services
- `checkout.html` Prototype checkout
- `listing.html` Property listing
- `dashboard.html` Seller dashboard

This is a portfolio prototype. Payments, CRM, authentication and database functionality are represented as UX/product flows rather than live production integrations.
