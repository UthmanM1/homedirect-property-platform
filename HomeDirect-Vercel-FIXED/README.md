# HomeDirect Property Selling Platform MVP

Original portfolio concept demonstrating a functional property-selling platform workflow.

## Pages
- Homepage
- Pricing and services
- Seller onboarding
- Property details
- Service add-ons
- Checkout
- Payment confirmation
- Property listing
- Buyer enquiry
- Enquiry confirmation
- Seller dashboard
